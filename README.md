# Proyecto Portfolio Grupal

Estructura reorganizada para separar FrontEnd y BackEnd.

## Cómo usar

1. Abrir `BackEnd` en la terminal.
2. Ejecutar `npm install`.
3. Ejecutar `npm start` para iniciar el backend en `http://localhost:5000`.
4. Abrir `http://localhost:5000` en el navegador para usar el frontend integrado.

## Estructura

- `FrontEnd/` contiene la UI y los recursos estáticos.
- `BackEnd/` contiene el servidor Express y la API.
